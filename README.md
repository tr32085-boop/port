# 🎓 TCAS E-Portfolio | นายศุภกร หอมดอกพลอย

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) สำหรับยื่นสมัครเข้าศึกษาต่อในระดับอุดมศึกษา (ระบบ TCAS) จัดทำขึ้นเพื่อประกอบการพิจารณาคัดเลือกเข้าศึกษาต่อใน **คณะบริหารธุรกิจ สาขาการจัดการ มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตบางเขน**[cite: 1]

---

## 📋 ข้อมูลผู้จัดทำ

- **ชื่อ-นามสกุล:** นายศุภกร หอมดอกพลอย[cite: 1]
- **สถานศึกษา:** โรงเรียนธัญรัตน์ จังหวัดปทุมธานี[cite: 3, 4]
- **คณะและมหาวิทยาลัยเป้าหมาย:** คณะบริหารธุรกิจ สาขาการจัดการ มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตบางเขน[cite: 1]

---

## ✨ คุณสมบัติเด่นของเว็บไซต์ (Features)

1. **Single-File Architecture:** รวมโครงสร้าง HTML, CSS และ JavaScript ทั้งหมดไว้ในไฟล์ `index.html` เพียงไฟล์เดียว ไม่ต้องติดตั้ง Library หรือ Framework เพิ่มเติม
2. **Responsive Design:** รองรับการแสดงผลทุกขนาดหน้าจอ ทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน พร้อมเมนูแบบ Hamburger บนมือถือ
3. **Interactive Certificate & Activity Modal:** มีหน้าต่างป๊อปอัป (Modal) สำหรับแสดงรายละเอียดกิจกรรมและเกียรติบัตร พร้อมปุ่มเชื่อมต่อไปยังไฟล์หลักฐานบน Google Drive
4. **Thai Typography:** ใช้ฟอนต์ **Prompt** จาก Google Fonts เพื่อความทันสมัยและอ่านง่ายในภาษาไทย
5. **Ready for GitHub Pages:** สามารถอัปโหลดขึ้น GitHub และเปิดใช้งานเป็นเว็บไซต์สาธารณะได้ทันที

---

## 🗂️ โครงสร้างเนื้อหาภายในเว็บไซต์

- **หน้าแรก (Home):** แนะนำตัว คณะและมหาวิทยาลัยเป้าหมาย พร้อมปุ่มเข้าถึงไฟล์ Portfolio ฉบับเต็ม (PDF / Google Drive)[cite: 1]
- **ประวัติการศึกษาและเป้าหมาย (Education & Statement of Purpose):** ลำดับประวัติการศึกษาตั้งแต่ระดับประถมศึกษาจนถึงมัธยมศึกษาตอนปลาย พร้อมเรียงความแสดงเจตจำนง (Statement of Purpose) และทักษะสำคัญ[cite: 1, 3]
- **กิจกรรมและประสบการณ์ (Activities):** รวบรวมประสบการณ์การทำงานเป็นทีมและภาวะผู้นำ เช่น รองหัวหน้าพาร์ท Percussion วงโยธวาทิต การสอบคัดเลือก สอวน. สาขาภูมิศาสตร์ และการแข่งขันความเป็นเลิศด้านภูมิศาสตร์[cite: 1, 2]
- **เกียรติบัตรและรางวัล (Certificates):** แสดงเกียรติบัตรรางวัลชนะเลิศการแข่งขันตอบปัญหาทางวิชาการด้านภูมิศาสตร์ และเกียรติบัตรค่ายส่งเสริมศักยภาพนักเรียนกิจกรรมชุมนุม[cite: 4]
- **ส่วนติดต่อ (Contact):** ช่องทางการติดต่อและโซเชียลมีเดียสำหรับคณะกรรมการพิจารณาคัดเลือก
